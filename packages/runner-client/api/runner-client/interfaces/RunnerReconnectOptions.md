# Interface: RunnerReconnectOptions

Controls how a runner reconnect restores previously requested code.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-rerun"></a> `rerun?` | `boolean` | Rerun the last requested code after reconnecting. Defaults to `true`. |
